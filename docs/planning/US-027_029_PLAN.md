### Step 0: ExecutionResult N-leg 리팩터 (US-027 AC1,AC2)

**대상**: `executor.py:60-68`

```python
@dataclass
class ExecutionResult:
    status: ExecutionStatus
    legs: list[LegResult] = field(default_factory=list)
    rollback_cost: Decimal = Decimal("0")
    error: str = ""
    strategy_id: str = ""

    @property
    def leg1(self) -> LegResult | None:
        return self.legs[0] if len(self.legs) > 0 else None

    @property
    def leg2(self) -> LegResult | None:
        return self.legs[1] if len(self.legs) > 1 else None
```

- 기존 23개 construction site: `leg1=X, leg2=Y` → `legs=[X, Y]` 변환
- trade_consumer.py:305-308 fallback도 업데이트

알고리즘:
1. halt check + health check
2. acquire lock(exchange_id)
3. 순차 실행: orders[0] → orders[1] → ... → orders[N-1]

5. rollback_cost 누적
6. finally: release lock
